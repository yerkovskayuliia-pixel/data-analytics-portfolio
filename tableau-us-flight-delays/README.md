# US Flight Delays Dashboard (Tableau)

A one-page Tableau dashboard about flight delays and cancellations in the US.

**Sheets:** KPI tiles with sparklines (flights, delayed, cancelled, departure and arrival delay) · Delay reasons · Cancellation reasons · Departure vs arrival delay · Taxi time vs delay · Airport map · Rankings

**Open:** `us_flight_delays_dashboard.twbx` in Tableau Desktop or Tableau Reader. It is a packaged workbook with a data extract, so it works without the source files. No database connection is used.
